# StateWatch

StateWatch is an iPhone + Apple Watch wellness readiness app concept.

## MVP scope
- Uses HealthKit data to estimate daily readiness signals (recovery, sleep, stress/fatigue, activity load)
- Uses cautious wellness wording only (not a diagnosis)
- Keeps HealthKit data local on device for MVP
- Uses mock data for previews and tests

## Safety and privacy
- Not a medical diagnosis app
- Does not claim disease detection
- No HealthKit upload in MVP
- No use of HealthKit data for advertising, marketing, or data mining
