# Product Requirements Document (PRD)

## Product
StateWatch: iPhone + Apple Watch wellness readiness app.

## Problem
Users want a simple daily wellness state summary from existing HealthKit signals.

## MVP goals
- Summarize daily readiness with recovery, sleep, stress/fatigue, and activity context
- Show plain-language explanations and low-risk suggestions
- Keep all HealthKit data processing local

## Non-goals
- Medical diagnosis, treatment, or disease detection
- Cloud analytics on raw HealthKit data
- Advertising/marketing personalization based on HealthKit data
