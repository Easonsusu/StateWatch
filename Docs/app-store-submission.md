# App Store Submission Notes

## Current status

This repository is not App Store ready. It contains the initial foundation and placeholder code only.

## Required before submission

- Real Xcode project with iOS, watchOS, and test targets.
- HealthKit capability and usage descriptions.
- Privacy policy finalized to match implementation.
- In-app disclaimer and HealthKit permission education screens.
- No server upload of HealthKit data in MVP.
- Screenshots generated from mock data.
- Accessibility and small-screen review.

## Reviewer notes draft

StateWatch is a wellness reflection app for iPhone and Apple Watch. It uses Apple Health data only with user permission and keeps HealthKit data local in the MVP. It does not provide medical diagnosis, disease detection, treatment, or prevention claims.
